# Tattler for macOS

Tattler is a firewall and traffic inspector for the Mac: it shows which app connects where, asks
before new connections, and keeps apps (and AI coding agents) to the servers you allow.

- **Tattler Firewall** on the Mac App Store: the firewall, rules, blocklists, encrypted DNS and the
  connection monitor.
- **Tattler** from this repository's [releases](https://github.com/victordov/tattler-releases/releases):
  everything above, plus packet capture, HTTPS decryption and the `tattler` command-line tool.
  Updates itself.

## Support

Questions, bugs and feature requests: [open an issue](https://github.com/victordov/tattler-releases/issues/new).
Please say which edition and version you use (Tattler → About), and your macOS version.

## Privacy

Tattler collects nothing about you; everything it records stays on your Mac.
Read the [privacy policy](PRIVACY.md).
